An interactive 3D visualization of matrix multiplication using einsum notation. Built with Next.js, React Three Fiber, and Three.js.

## Features

- Einsum notation input for flexible matrix operations
- 3D visualization of input matrices, intermediate element-wise products, and the result
- Adjustable matrix dimensions and values via sliders
- Color-coded cells: red for positive, blue for negative, grey for zero

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
